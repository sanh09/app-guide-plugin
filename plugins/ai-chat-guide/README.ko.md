# appguide-tutor: Claude 앱 사용법 튜터

[English](README.md) | **한국어**

Claude 웹·데스크톱 앱을 첫 대화부터 커넥터·스킬까지 단계별로 가르치는 튜터입니다. 레슨마다 짧은 설명, 새 채팅에서 해 보는 실습, 퀴즈가 있습니다. 학습자가 쓰는 언어로 답하고, 코딩 지식은 필요 없습니다.

## 레슨

1. 첫 대화와 화면 둘러보기
2. 좋은 질문 쓰기
3. 파일·이미지 올리기
4. 웹 검색 · Research · 생각(thinking)
5. 프로젝트
6. 나에게 맞추기: 지침 · 메모리 · 이전 채팅 검색 · 시크릿 채팅
7. 아티팩트와 파일 만들기
8. 음성 모드와 모바일
9. 커넥터로 앱 연결하기
10. 스킬
11. 여러 기능 조합하기
12. 안전하고 믿을 수 있게 쓰기

## 시작하기

대화를 시작하고 배우고 싶은 내용을 말하세요. 예:

- "Claude 처음 써 봐요. 사용법 알려 주세요"
- "프로젝트 기능이 뭐예요?"
- "메모리 끄는 법 알려 주세요"

메뉴 경로·명령어·설정은 공식 문서로 확인해 `skills/ai-chat-guide/references/facts.md`에 정리했습니다. 퀴즈 정답은 별도 파일에 두고 채점할 때만 읽으므로, 답하기 전에 보이지 않습니다.

## 설치

Claude 웹 또는 데스크톱 앱에서 **사용자 정의(Customize)** → **플러그인(Plugins)** → **추가(Add)** → **마켓플레이스 추가(Add marketplace)** → **저장소에서 추가(Add from a repository)**로 `sanh09/app-guide-plugin`을 입력한 뒤 `appguide-tutor`를 추가하세요. 이 플러그인에는 스킬 `ai-chat-guide`가 들어 있습니다.

## 플러그인이 하는 일

- 스킬 하나(지침과 참고 파일)만 추가합니다. 훅, MCP 서버, 스크립트는 없고, 데이터를 어디로도 보내지 않습니다.
- 학습 기록을 저장하지 않습니다. 새 채팅에서는 어디부터 시작할지 다시 묻습니다.
